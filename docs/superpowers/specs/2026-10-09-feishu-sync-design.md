# 飞书业务复盘同步

用户已确认：数据库为主存储，独立飞书 Base 单向展示场次、10 分钟复盘和真实采样。AI 与人工字段分开，不写入现有业务表，不影响正在进行的直播。

独立 Python worker 每五分钟读取现有 review API 和 PostgreSQL 采样证据，以 lark-cli user 身份写入已创建 Base。通过明确主播白名单与开始日期筛选真实场次，禁止导入历史模拟测试。当前白名单为一星老师，2026-10-09 起。前台填写仍在网页进行；飞书是副本，不能当作回写入口。

每次完整分页读取目标表同步键，查重后新增或更新，单进程文件锁防并发。远端成功后才原子保存本地哈希；网络结果未知时下一轮先重新查远端键，避免直接重放 create。重复同步不得新增重复行。跨表先写场次再用真实 record_id 建关联。缺失人数为空，零为零。保留已知采样 id、采样与接收时间，不假造。

运行依赖服务器已有 lark-cli 用户授权；不复制本机凭据。专用 systemd timer，失败返回非零并保留安全状态日志；不重启直播服务。配置仅含表 ID、主播白名单等，凭据通过服务器现有受限环境读取，不提交 Git。
