# 抖音主播后台取数测试版 0.1.0

这是独立 Chrome 扩展，适配 `https://anchor.douyin.com/anchor/dashboard`。不依赖旧罗盘插件或 Windows EXE，可用于 Mac / Windows Chrome。当前验证了逻辑测试，尚未完成真实页面安装采集验收。

## 安装与验证

1. 解压测试包。在 Chrome 扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，选中包含 manifest.json 的 anchor-collector 文件夹。
2. 打开已登录的主播后台“直播大屏”；若安装前已经打开，请刷新该后台页面，使脚本加载。
3. 点击插件，输入与页面右上角一致的主播昵称，点击“开始每10秒取数”。保持大屏前台可见，电脑不休眠。
4. 等待至少 30 秒，插件应保存约 3 条记录；对比在线人数、点赞等数值后，点击“导出 JSON”检查时间戳、间隔和数据口径。
5. 测试完点击“停止”。不改变直播状态、不发送评论、不写业务表。

## 边界

- 仅读取“直播热度”至“直播趋势图”之间已渲染的指标文字；不读取接口响应、Cookies 或登录凭据。依据 2026-09-24 可见的大屏标签编写，DOM 文本顺序仍待实页验证。
- 近1分钟/累计流量漏斗未接入；人均停留单位未在观察页面确认，保留原值，unit=null。
- 每10秒是浏览器定时器目标，不保证后台或休眠时精确执行。记录真实采样时刻及间隔，超过15秒标记gap；无法补出未采样值，也不知道平台自身刷新间隔。
- 账号以顶部区域昵称人工绑定，只是测试校验，不是稳定平台账号ID。无法确认昵称或指标时暂停入库。
- 每次开始创建独立采集批次，platformSessionId=null。尚未实现平台场次ID、开关播自动识别、自动恢复与跨场次去重。浏览器重启默认关闭，避免标签ID变化串账号。
- 只接收绑定标签页的采样；Service Worker 串行存储，9秒内重复消息跳过，默认关闭。最多5000条，满后停止不覆盖。
- 数据仅在 chrome.storage.local，无上传/同步；卸载或清除扩展数据会丢失，请先导出。导出的真实数据不要提交公开仓库。
- 这一版本用于取数准确性验收，不是已完成的全自动正式版。

## 0.2.0 调度更新

采样10秒保持不变；增加 Chrome alarms 每5分钟批量上传触发、停止后尝试上传、浏览器重启后尝试补传。积压每次最多300条，正常5分钟约30条；批次持久保存，上传失败重用相同batchId与原始记录。只有服务端回执同时匹配batchId和acceptedIds才移出已确认记录，新产生的记录不会误删。网络请求不占用采样存储队列。当前存储仍是chrome.storage.local，尚未迁移IndexedDB。

upload-config.mjs 的 INGEST_URL 默认null，因此现阶段不会上传任何数据。启用前还必须完成服务器接收/幂等接口、短期仅上传凭证下发（uploadToken）、精确上传域名host_permissions授权和实页验收；当前没有配置界面，不要在代码中写凭据。时钟休眠和浏览器节流可能延迟alarm，不保证严格5分钟。

导出的是当前待传记录；将来已确认上传的记录由后端保存，不再包含在本地导出里。自动关播识别未接通，因此目前只有手动停止会触发尾批上传。

后端 backend/analysis.py 提供从真实开播时间起算的10分钟区间规划，确认关播后包含不足10分钟的末段。这是纯窗口函数，尚未接入分析任务队列、数据完整度判定、迟到重算、人工编辑保护或AI生成；不会声称已自动分析。

### 0.3.0 上传配置

在弹窗“上传设置”填写完整 `/api/metrics/batches` 接口地址和后端令牌。保存时仅请求该域名访问权限；支持 HTTPS，另允许 `http://127.0.0.1` 本机联调。令牌保存在当前 Chrome 扩展本地存储，不写源码、不在状态或导出记录中返回。仅应在受信任的操作电脑使用。正常每五分钟上传，停止时补传，也可“立即上传”。返回确认前不删除缓存。部署版需配置正确域名和令牌；此前已安装的 0.2.0 需在扩展管理页重新加载。

每批消息 `{schema:1,batchId,records}`，最多300条；每条保留 id/runId/teacher/capturedAt/metrics 和 gap/foreground 等质量标记。没有平台场次时 platformSessionId 为 null，后端显式绑定场次。

### 0.3.2 采集状态
弹窗显示最近确认上传时间和当前采集批次前8位；上传失败区分凭证、权限、格式、冲突、限流及服务错误。网络异常或回执不匹配时继续保留本地记录。
公网复盘页的“采集与处理状态”每15秒查询已入库记录，并显示当前场次关联数量、关联方式、ASR和总结状态。服务器不能观察尚未上传的本地队列，最近采样与待上传数量仍需在插件查看。固定OBS入口按主播昵称与采样时间关联，请保持绑定昵称一致。插件更新需在Chrome扩展管理页重新加载；无需清空存储或重新配置令牌。

### 0.3.3 异常与收尾提示
弹窗区分等待首条、超过30秒未采样、最早待传记录积压超过6分钟、停止后尾批未清空和从未采样。只显示上传是否配置，不向弹窗返回上传令牌。网页OBS接入页增加只读开播检查；复盘状态显示已登记录像、ASR及总结收尾，明确无法代替插件确认本地尾批。阈值提示不推断主播是否正在直播，也不会自动开播。

### 0.4.0 手动结束确认
“结束本场采集”停止采样并持久保存结束事件，立即尝试上传全部尾批（最多5000条），之后在相同认证上传入口提交kind=finish事件。后台以runId幂等核对数量、主播及最后采样时间后封存批次。失败在后续五分钟调度或立即上传时重试；重启不清除事件。新批次记录累计采样数，旧批次缺少总数只登记为未完整核验。开始新批次前需先结束上一批；不自动判断抖音或OBS已停播。网页按批次显示结束确认，仍需独立确认音视频链路。
