# 「谛听」百应场控数据采集 WR-P-009-FIX1-TEST-20260921 一键安装

请使用与电脑系统对应的安装包，先完整解压，再运行安装文件。

## macOS

- 安装：双击 `安装.command`
- 卸载：双击 `卸载.command`
- 若首次运行被系统阻止：右键脚本，选择“打开”，再确认“打开”

## Windows

- 安装：双击 `setup.cmd`（也可使用 `安装.cmd`）
- 卸载：双击 `uninstall.cmd`（也可使用 `卸载.cmd`）

## 安装器会做什么

- 查找并复用已有 Chrome、Node.js、lark-cli 路径；
- 找不到 Node.js 时，从 Node.js 官方地址安装 Node.js 24 LTS 到用户目录；
- 找不到 lark-cli 时，使用飞书官方命令安装；
- 检查 lark-cli 登录和目标多维表权限；
- 安装时请求 Base、Drive、Contact 和 Wiki 所需权限；
- 部署 Chrome 扩展；
- 安装 Native Messaging；
- 保存已识别路径，重复安装时直接复用。

WR-P-009-FIX1-TEST-20260921 保留直播日期日历和“当天/次日”结束日期选择，开始与结束时间改为人工输入 `HH:MM:SS`。跨零点直播会生成第二天的完整结束时间，直播时长限制为大于 0 且不超过 24 小时；不会新增或提交“跨天状态”字段。本修订版同时让“消耗”按相同直播间 ID 的历史记录完成累计扣减。升级旧版时必须重新运行完整安装包。

## 唯一需要人工确认的步骤

Chrome 个人版不允许普通本地脚本静默安装扩展。安装器会自动打开扩展程序页与扩展目录，首次安装时请按屏幕提示点击“加载已解压的扩展程序”。

## 卸载范围

卸载只删除谛听扩展、Native Messaging 和安装状态；不会删除 Node.js、lark-cli、飞书登录状态或 Chrome。
